Download LATYS

One installer for Windows 10 and 11. It sets itself up in a few seconds and tells you when an update is ready.

Run the installer

LATYS is new and not yet code-signed, so Windows may show a blue SmartScreen box the first time. To continue:

  1. Click More info.
  2. Check the app name says LATYS-setup.exe, then click Run anyway.

Only download LATYS from latys.app or the official GitHub release. The installer adds Start menu and desktop shortcuts and appears in Add or remove programs, so you can uninstall it like any other app.

Install at least one agent

LATYS runs the official tools from each AI company. Open PowerShell, paste one command, then sign in once. LATYS finds the tool on its own.

Claude Code Docs

irm https://claude.ai/install.ps1 | iex

Then run claude to sign in.

Codex Docs

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Then run codex to sign in.

OpenCode Docs

npm install -g opencode-ai

Needs Node.js. Then run opencode and type /connect.

Grok Docs

irm https://x.ai/cli/install.ps1 | iex

Then run grok login.

Gemini, Cursor, Antigravity, Kimi and Hermes install from their own sites. The Launch Agent window in LATYS links to each one.
