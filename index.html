Get started

Up and running in minutes

LATYS runs the agents you already use. New to them? Each one installs with a single PowerShell command.

1

Install LATYS

Download the Windows app and run it. No account needed.

2

Install an agent

Paste one command into PowerShell, from the official installers below.

3

Sign in and go

Sign in once with the agent's own login, hit Re-check in LATYS, and launch.

Claude Code
Setup guide ↗
irm https://claude.ai/install.ps1 | iex

Then run claude once and sign in with your Anthropic account.

Codex
Codex on GitHub ↗
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Then run codex and choose Sign in with ChatGPT.

OpenCode
OpenCode docs ↗
npm install -g opencode-ai

Needs Node.js first, if you don't have it.

Then run opencode and type /connect to add a model provider.

Grok
Grok Build by xAI ↗
irm https://x.ai/cli/install.ps1 | iex

Then run grok login and sign in with your xAI account.
