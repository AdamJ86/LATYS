Get started

Set up in minutes

One PowerShell command per agent.

Claude Code
Docs ↗
irm https://claude.ai/install.ps1 | iex

Then run claude to sign in.

Codex
Docs ↗
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Then run codex to sign in.

OpenCode
Docs ↗
npm install -g opencode-ai

Needs Node.js. Then run opencode and type /connect.

Grok
Docs ↗
irm https://x.ai/cli/install.ps1 | iex

Then run grok login.
